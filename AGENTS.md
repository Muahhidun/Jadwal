# Jadwal — исламское приложение напоминаний о поклонении

Этот файл автоматически читается Codex в начале каждой сессии. Он — точка входа для любого агента, продолжающего работу.

## Что это за проект
Мобильное приложение (Flutter, iOS + Android) — «ассистент поклонения»: напоминания, привязанные ко временам молитв (утренние/вечерние зикры, сура аль-Кахф и час дуа в пятницу), по тапу открываются сами зикры. Казахстан-first. Бесплатно, без рекламы, без бэкенда.

**Полный план, решения и архитектура: [PLAN.md](PLAN.md) — читать обязательно перед любой работой.**

## Жёсткие ограничения (нарушать нельзя)
1. **Никаких счётчиков-тасбихов** и цифровых счётчиков зикра — владелец считает это религиозным нововведением. Только отметка «выполнено» (галочка) на зикр целиком.
2. **Только достоверный религиозный контент** с указанием источника (сборник, номер хадиса) у каждого зикра. Религиозные тексты не придумывать и не «улучшать» — контент собирает и утверждает владелец.
3. **Никакой геймификации-самообмана**: без очков, бейджей, рейтингов. История/календарь постоянства — да.
4. Бесплатно, без рекламы, без сбора данных, всё хранится локально.

### Грабли, стоившие часа — не наступать заново
1. **Роль ключа API обязана быть «Администратор».** С ролью «Менеджер приложения»
   выгрузка падает с `Cloud signing permission error`: этой роли не хватает прав на
   выпуск сертификата. Роль ключа после создания изменить НЕЛЬЗЯ — только новый ключ.
2. **Ключи `authenticationKey*` внутри ExportOptions.plist Xcode игнорирует** и всё равно
   лезет в аккаунты (`Failed to Use Accounts`). Передавать их флагами командной строки.
3. **Файл `.p8` скачивается ровно один раз** — второй попытки Apple не даёт, ссылка
   «Загрузить» исчезает навсегда. Встроенная панель браузера Claude файл сохраняет,
   но в `~/Downloads` он появляется с задержкой в несколько минут: не считать загрузку
   провалившейся сразу и не плодить лишние ключи, а подождать и перепроверить папку.
4. **Сборка требует симулятор watchOS**, иначе `No available simulator runtimes for
   platform watchsimulator`. Ставится через `xcodebuild -downloadPlatform watchOS`
   (~4 ГБ). Device-сборка тоже это требует — обойти нельзя.

### Android / Google Play
Внутреннее тестирование, ключ подписи `app/android/upload-keystore.jks` + `key.properties`
(оба вне Git). Сборка: `cd app && flutter build appbundle --release` →
`app/build/app/outputs/bundle/release/app-release.aab`. Сервисного аккаунта Play API
на машине НЕТ, поэтому загрузка в Play Console — вручную, перетаскиванием файла.

## Нижний экран «Страницы» и кнопки уведомлений (29.09.2026, ветка `prototype/vertical-pages`)

Владелец выбрал вертикальные страницы вместо классического нижнего экрана:
**Кибла ↑ Таймер ↓ Сегодня ↓ Постоянство**. Ветка ещё не влита в `main`; вид включается в
«Оформление → Нижний экран → Страницы» (по умолчанию пока классический — при слиянии
сделать страницы единственным видом и убрать переключатель).

- Код: `app/lib/screens/day_pages.dart` (part of `home.dart`). Все переходы — хореография
  элементов, вычисляемая из положения пальца (`_Beat`, `_Leave`, `_QReveal` в Кибле):
  сначала уходит прежнее, потом приходит новое. Доводка после свайпа неспешная
  (260 + 760·путь мс). Taptic Engine щёлкает, когда элемент встаёт на место (`_beats`).
- «Сегодня» — два отдельных блока (намазы, дела). Смешивать их в одну ленту НЕЛЬЗЯ: этот
  вариант (ветка `prototype/day-timeline`) владелец отверг — «потерялись оба».
- Отвергнуто владельцем: дуга пути солнца, крупные заголовки страниц, повтор даты и города
  на нижних страницах, надпись «окна на сегодня закрыты».
- Фирменный фон страниц и листов — `app/lib/theme/ornament.dart` (узор восьмиконечных звёзд
  + золотое свечение). Листы настроек/напоминаний (`settings_shell.dart`) — в том же стиле:
  золотые подписи разделов, золотой акцент, разделы появляются по очереди.
- Календарь: пустые прошедшие дни — точка (`softEmpty`), дни до первого запуска не
  рисуются (`AppState.firstUseDate`), при свайпе числа слетаются (`assemble`).

**Кнопки в уведомлениях** (`notifications.dart`): у дел — «Выполнено» и «Через 10 мин»,
у намазов — нет. Payload — JSON (`NotificationPayload`), старые строки поддерживаются.
Фоновая обработка — `notificationActionBackground` + `setPluginRegistrantCallback` в
`AppDelegate.didInitializeImplicitFlutterEngine` (UIScene). Отложенные хранятся в
`notif:snoozes` и переживают `reschedule`. Тап по уведомлению в фоне теперь открывает
чтение (`onOpen`), при возврате состояние перечитывается (`AppState.reloadFromDisk`).

Также: минимальная iOS 15.0; ручной сброс онбординга по метке сборки удалён из `main.dart`;
иконка пересобрана (у нижнего слоя тени был срезан низ).
