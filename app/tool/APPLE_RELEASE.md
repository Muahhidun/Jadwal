# Обязательные ворота перед TestFlight

После инцидента 25/26 запрещён прямой export/upload неподписанного архива.
`codesign --verify --deep --strict` подтверждает целостность, но **не** наличие
App Group. В исходниках разрешение было, а cloud signing unsigned-архива
подписал все четыре компонента без него. Приложение и виджеты потеряли общее
хранилище. Успешный Upload / Beta Review эту ошибку не обнаруживают.

1. Собрать свежий архив всех четырёх компонентов. Если сборка выполнялась
   с `--no-codesign`, перед экспортом подписать **архив**, а не только отдельную
   копию Runner.app, существующей совместимой identity и профилями с App Group.
   Не создавать новые сертификаты/профили и не менять capability без согласования.
2. Выполнить `python3 tool/verify_apple_release.py /absolute/Runner.xcarchive`.
   Неподписанный архив обязан быть отклонён. Существующие пакеты 25/26 и логи
   не перезаписывать — они нужны для расследования.
3. Экспортировать **в локальный IPA** (`destination=export`, не `upload`).
   Использовать имеющиеся ASC-учётные данные; не выводить ключи в логи/чат.
4. Выполнить `python3 tool/verify_apple_release.py /absolute/Dauam.ipa --distribution`.
   Обязателен PASS для Runner, iPhone WidgetKit, Watch app и Watch widgets:
   настоящий signed entitlement `group.kz.dauam.shared`, профиль, идентификаторы,
   согласованный номер, release-подпись без отладки. При любой ошибке — стоп.
5. Только при отдельном разрешении владельца загрузить **тот же проверенный IPA**.
   Хранить SHA-256 IPA, оба отчёта ворот и подтверждение ASC. Повторно номера
   25/26 не использовать; следующая загрузка требует свободного номера.

Этот gate ничего не подписывает, не устанавливает и не публикует. Его PASS
не заменяет физическую проверку обновления виджетов iPhone и циферблата Watch.
Не удалять приложение/данные тестеров ради восстановления: новый корректный
пакет должен пересохранить снимок при открытии приложения и синхронизировать часы.

## Согласованная подпись 27 от 24.10.2026

После явного разрешения владельца создан новый Apple Distribution и четыре
IOS_APP_STORE-профиля без отзыва прежних сертификатов. Прямую подпись Distribution
можно выполнить `node app/tool/sign_apple_archive.cjs /absolute/Runner.app 27 /absolute/signing-config.json`.
Конфиг содержит identity SHA1, отдельную keychain, distribution=true и карту
bundle ID → profile UUID; ключи/пароли хранятся только в закрытой папке вне Git.
Скрипт не создаёт сертификаты/профили и не экспортирует/не загружает пакеты.
В этом варианте manual local export использует ту же identity и четыре UUID;
оба distribution gate обязательны. Подписанный для App Store архив не является
development-пакетом для прямой установки на устройство; обновление через TestFlight.
